== 📖 Objectif du module
Ce dossier contient l'interface graphique de l'Agence de Voyage, développée avec le framework **Angular**.
C'est la vitrine du projet. Elle offre une expérience utilisateur riche (UX) et s'adapte dynamiquement au profil connecté (Client ou Administrateur).

**Fonctionnalités principales :**
* 🔄 **Double Sélecteur Dynamique** : Basculement à chaud (sans redémarrage) entre le serveur Java (Spring Boot) et le serveur Python (Django) via le `ServeurService` ET basculement instantané vers l'interface **React** grâce à un bouton dédié dans la barre de navigation.

* 🔍 **Recherche Avancée & IA** : Recherche classique, recherche en langage naturel (texte) et recherche **vocale** (grâce à l'API `MediaRecorder` du navigateur).

* 💳 **Paiement Integrated** : Interface de paiement sécurisée via Stripe Elements.

* 🛡️ **Panel Administrateur Complet** : Gestion des vols, transfert de billets, bannissement d'utilisateurs et modération des avis.

* 🎫 **Espace Client** : Historique des réservations, génération de carte d'embarquement et dépôt d'avis (écrit ou vocal).

== 🏗️ Architecture et Fichiers Clés
Le projet respecte les standards modernes d'Angular (sans modules, utilisation du control flow `@if` / `@for`) :

* `src/app/app.routes.ts` & `app.config.ts` : Configuration du routage et des fournisseurs de services.
* `src/app/components/` : Ensemble des composants standalone de l'application (barre de navigation, panel admin, catalogue...).
* `src/app/services/` : Services Angular gérant les requêtes HTTP et l'état de l'application (`AuthService`, `ServeurService`...).
* `src/app/services/serveur.service.ts` : Composant central du sélecteur dynamique qui commute l'URL de base des requêtes vers le port Spring (8080) ou Django (8000).

== 🐳 Lancement de l'Application

Il existe deux manières de lancer ce module Front-end.

=== Méthode 1 : Via Docker (Recommandé)
Cette méthode garantit un environnement isolé et prêt pour la production.

. Ouvrez un terminal dans le sous-dossier Angular.
. Construisez l'image Docker :
+
[source,bash]
----
docker build -t voyage-angular .
----
. Démarrez le conteneur en liant le port interne 80 de Nginx au port 4200 de votre machine :

[source,bash]
----
docker run -p 4200:80 voyage-angular
----
L'interface est accessible sur **http://localhost:4200**.

[[lancement]]
=== Méthode 2 : Lancement manuel de développement (Live Reload)
Cette méthode est idéale si vous modifiez le code (HTML/CSS/TS) car la page s'actualisera toute seule.
_Prérequis : Node.js et Angular CLI installés._

. Ouvrez un terminal dans ce dossier.
. Installez toutes les bibliothèques `npm` :
+
[source,bash]
----
npm install
----
. Lancez le serveur de développement Angular :
+
[source,bash]
----
ng serve
----
L'interface est accessible sur **http://localhost:4200**.

== ⚠️ Avertissement de fonctionnement
Bien que l'interface graphique puisse s'afficher seule, **elle est totalement inutile sans un serveur back-end pour lui fournir les données**.

* Assurez-vous d'avoir lancé au moins le backend **Spring Boot (8080)** ou **Django (8000)** en parallèle.

* L'IA fonctionne sans backend local puisqu'elle appelle directement le microservice distant déployé sur Hugging Face.

== 🛑 Comment arrêter le serveur ?
* **Si lancé via Docker :** Faites `Ctrl + C` dans le terminal.
* **Si lancé via ng serve :** Faites `Ctrl + C` dans le terminal.
